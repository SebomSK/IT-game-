Privacy Notice

Last updated: November 13, 2026

TicketQuest is a browser-based game. It does not have player accounts, collect email addresses, or send game progress to an application server.

Data stored in your browser

The game stores your chosen display name, generated in-game login, progress, ticket notes, and settings in this browser's localStorage. This data stays in the browser unless you explicitly export a save file. Anyone with access to the same browser profile may be able to access it.

You can remove your game save using Reset Progress or by clearing this site's browser storage. Exported save files are ordinary JSON files and are not encrypted. Avoid using your real name or including sensitive information in notes.

Hosting and network requests

The site is hosted by GitHub Pages. Your browser requests the game files from GitHub to load the site. GitHub may process technical request information, such as IP address and browser details, under GitHub's Privacy Statement.

The game itself does not send your name, progress, or notes to GitHub or another application server. It does not include analytics or advertising trackers.

Cookies, accounts, and passwords

The game does not set tracking cookies and does not provide accounts or passwords. It uses localStorage for game progress and preferences. Do not send passwords or save files through Discord.

Contact

For questions about TicketQuest, contact realbigrussian on Discord. Do not send passwords or other sensitive information.

This is a technical privacy notice, not legal advice. Review it for your jurisdiction before adding accounts, email collection, analytics, or other data processing.
